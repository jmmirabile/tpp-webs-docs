# Workflow & Approvals

> **Status: placeholder.** Full chapter coming in Phase 2.

TPP can require manual sign-off before a certificate action (e.g. issuance)
completes, via approval **tickets** attached to a config object DN. See
[`/Workflow`](../reference/workflow/overview.md) for ticket create/approve/
reject/status endpoints.

A separate, code-signing-specific ticketing system (`/Flow`) exists for
CodeSign pre-approvals — don't confuse the two.
