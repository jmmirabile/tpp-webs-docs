# Permissions & Identity

> **Status: placeholder.** Full chapter coming in Phase 2.

TPP's Identity system models users, local/AD groups, and group membership,
layered under by "Teams" (named groups with owners + asset/product scoping).
Object-level access control is a separate ACL system keyed by GUID, type,
and principal. See [Identity & Access](../reference/identity-access/overview.md).
