# Workflow

> **Status: placeholder.** Not yet formalized into the OpenAPI spec — full

Covers **`/Workflow`** (approval tickets attached to config objects — e.g. a
certificate change requiring sign-off) and **`/Flow`** (a separate,
code-signing-oriented ticket/approval system used by CodeSign pre-approvals —
don't confuse the two). See [Workflow &
Approvals](../../guide/08-workflow-approvals.md).
